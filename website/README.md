# Syntriass Labs Website Preview

Static website imported from the Stitch sovereign UI design package.

## Preview

From the repository root:

```bash
python3 -m http.server 4173 -d website
```

Then open:

```text
http://127.0.0.1:4173/
```

## Files

- `index.html` - single-page Syntriass Labs landing page.
- `assets/syntriass-logo.jpeg` - local Syntriass logo used in the hero.
- `design/SOVEREIGN_INDUSTRIAL.md` - Stitch design system notes.
