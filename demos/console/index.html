Catch the lying agent

An AI agent's own log says one thing. Independent kernel-level evidence shows what it actually did.

What happens

  • A scripted test agent does its task, and secretly opens a network connection and writes a file outside its workspace. Its own log omits both.
  • Sniffer Dog watches from the Linux kernel and binds each action to the exact process. A collector key the agent never sees signs the evidence.
  • auditd, a separate kernel subsystem, cross-checks it.
  • Anyone can verify the evidence offline. Changing one byte breaks it.

Not claimed

  • That it catches any real-world agent, or an agent built to evade it.
  • Its overhead, which has not been measured.

Post-quantum in one switch

Proof of concept. An unmodified network program gets a post-quantum protected connection, switched on at launch.

What happens

  • Two containers run the same unmodified netcat binary. Its hash is unchanged in every phase.
  • Without the overlay, the message crosses the wire in clear. With it, the message is delivered but is never on the wire.
  • Remove the identity, offer a weaker fallback, connect without the overlay, or impersonate: nothing is delivered.

Not claimed

  • TLS interoperability (both ends run the overlay), production readiness, or zero overhead.
  • The algorithms (hybrid X25519 + ML-KEM-768, ML-DSA-65) come from the source code. The capture shows only a ~13 KB handshake.
