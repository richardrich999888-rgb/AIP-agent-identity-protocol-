# AIP Roadmap — Accountability Infrastructure for Autonomous AI

Mission test for every item: **"Does this strengthen accountability?"**
If no → rejected. (Runtime firewalls, reputation engines, quantum
experiments, and generic AI features fail this test and are out.)

Status legend: ✅ shipped (in this repo, tested) · 🔨 next · 🗺 planned

## Done (this repo, verified by tests)

- ✅ **EvidencePacket v1** — canonical encoding, deterministic hashing,
  agent + per-action signatures, trace/receipt bindings, counterparty
  countersignatures, trust floors (`aip-protocol`).
- ✅ **Verification engine** — 14 named rules, full-report (no
  short-circuit), derived trust floors, tamper classification.
- ✅ **Accountability graph** — Human → Authority → Agent → Decision →
  Action → Receipt reconstruction, connectivity validation, JSON/DOT export.
- ✅ **Banking design-partner demo** — end-to-end flow + tamper-and-detect.
- ✅ **Open spec v0.1-draft** (`AIP_SPEC.md`).
- ✅ **Credibility cleanup** (`AUDIT_CORRECTIONS.md`); build fixed;
  reputation overflow fixed; non-reproducing benchmarks deleted.

## Phase 4 — Enterprise Accountability Console 🔨

Web viewer: upload packet → verify → visualize graph → export evidence →
simulate tampering. Every UI check maps 1:1 to an engine rule — the UI may
not contain verification logic of its own. (Frontend consuming
`VerificationReport` + graph JSON; the Rust engine compiled to WASM or
behind a thin service.)

## Phase 5 — SDKs 🔨

Priority: **TypeScript, Python, Rust (publish existing crate)**.
Two-line developer experience: generate packet, verify packet, export packet.
Cross-language conformance suite: shared JSON test vectors generated by the
Rust reference implementation — an SDK ships only when it passes them.
(Reason this isn't in-repo yet: cross-language canonical-encoding parity
without a conformance suite is how silent forgery bugs are born.)

## Phase 6 — Framework integrations 🗺

MCP middleware first (every tool call emits evidence automatically), then
LangGraph callbacks, OpenAI Agents SDK tracer, CrewAI plugin. Goal: two
lines of code per framework.

## Phase 7 — Evidence Vault (the product) 🗺

Managed/self-hosted: packet storage, verification on ingest, search by
principal/agent/decision, retention policies, compliance export (Evidence
Packet bundles for auditors). Explicitly NOT: SIEM, firewall, detection,
runtime sandboxing, reputation.

## Hardening (continuous)

- Authenticated multi-tenant verification service (replaces the
  `aip-service` prototype), Postgres-backed state, KMS/HSM keys, rotation.
- Transparency-log anchoring of packet hashes (witnessed evidence).
- Real TEE quote verification; provenance commitment validation.
- CI: build + full test suite on every commit; no green badge without it.

## 12-month objectives

1. EvidencePacket accepted by one auditor.
2. One regulated-enterprise pilot.
3. One SDK used by external developers.
4. One framework integration in the wild.
5. One production verification service.
