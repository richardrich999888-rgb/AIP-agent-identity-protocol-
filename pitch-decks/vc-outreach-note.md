# VC Outreach Note

Subject: AIRON Agent Passport - infrastructure for trusted AI agents

Hi [Name],

We are building AIRON Agent Passport: a portable identity and verification layer for AI agents operating in regulated workflows.

The core problem is simple: agents are entering financial, enterprise, and critical workflows without a durable proof of who authorized them, what they were allowed to do, whether that authority was still valid, and whether the action can be verified later.

AIRON solves this with:

- Agent Passport: a signed credential that travels with the agent across LangChain, notebooks, APIs, and audits.
- PASS / TOXIC verification: an offline verifier for tamper-evident agent authority and lineage.
- EvidencePacket lineage: human authority -> agent decision -> final action.
- AEGIS roadmap: kernel-level enforcement for high-value network paths.

Commercial model:

- Identity-as-a-Service: passport issuance, registry, revocation, and scoped delegation.
- Audit-as-a-Service: EvidencePacket storage, verifier reports, exports, and retention.
- Usage-based pricing: metered issuance, verification, revocation, and evidence actions.
- Enterprise / defense licensing: private control plane, support, air-gapped deployment, and AEGIS nodes.
