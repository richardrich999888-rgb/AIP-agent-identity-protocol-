# Known limitations and release blockers

1. Process/image sampling is not atomic or historical event-time attestation.
   Exec-away-and-back, hostile kernel/filesystem and memory-resident modifications
   are outside the new consistency check. Source mechanism limits are preserved.
2. Process identity is not a logical AI-agent identity. Signed launch/request
   binding for concurrent in-process agents and the full graph exporter are open.
3. Request/authority agreement cannot prove an unsupported tool effect or business
   outcome. Existing same-run `CannotProve` remains correct.
4. No fresh Shadow AI ground-truth experiment, detection rates, false-attribution
   rate, event-loss-under-load, causal overhead or multi-agent capacity matrix.
5. Mandatory cross-branch OTel/OPA and later framework work is not consolidated.
   Current upstream API/advisory/license closure and genuine task matrices remain.
6. No independently administered simultaneous two-host deployment, production key
   custody, institutional enrollment or external claims approval.
7. No clean customer-host installation/restart/recovery/uninstall or complete
   air-gap dependency bundle qualification. Kubernetes privileges remain unaccepted.
8. New P0-048 CI/security work advanced concurrently. Original P0-057 source is
   pinned; synthetic-merge results have a separate scope. A passing archival
   classification does not remediate live deployment findings.
9. Local controlled exec tests use real non-AI processes and test-only scheduling
   hooks. Their signed process samples are same-host lab evidence, with no coverage
   attestation. Hosted native tests use disposable-VM privilege and fixture clock
   windows where stated by the inherited test. None is a customer pilot.
10. No complete live five-scene rehearsal, final independent review, production
    compatibility, vendor endorsement or enterprise-readiness claim.
11. Fresh same-run recovery run `43582459576` failed because its authorised
    request had no signed Forwarded receipt. The tool ran; the original archive
    cannot establish which gateway hook/state failed. The new journal export is
    diagnostic only, not a repair or evidence substitute. This remains a release
    blocker even though the 27-check real gateway integration passed separately.
    The subsequent hosted attempt `43583751360` passed all three scenes with
    captured diagnostics; it did not establish or repair the earlier cause.
