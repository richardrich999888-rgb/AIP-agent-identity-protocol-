# AIRI — Evidence Classification and Limitations

For each property: what is claimed, what class of evidence supports it, and
where the claim stops. Classes follow the forensic audit's discipline.

| Class | Meaning |
|---|---|
| **CODE-PROVEN** | Read directly from source at a cited path |
| **TEST-PROVEN** | A test exercises the property itself, not a stand-in |
| **EXECUTION-PROVEN** | Demonstrated by running code across a real boundary |
| **DOCUMENTED** | Asserted in a document; not independently verified |
| **NOT_DETERMINABLE** | Cannot be established from the current codebase |

## 2. Properties NOT established

Each is a gap, not a nuance.

| # | Not established | Why | Class |
|---|---|---|---|
| N-1 | That any claimed action occurred | AIRI is self-report; occurrence needs observation | by design |
| N-2 | That a claimed external effect landed | The process that made the call cannot know | by design |
| N-3 | That a provider served the model requested | Hosted APIs return an unverifiable identifier | NOT_DETERMINABLE |
| N-4 | That specific weights were loaded | A digest the agent computes is a statement about a file, not about runtime memory | NOT_DETERMINABLE |
| N-5 | That XLA, a native kernel, or a GPU executed anything | Framework telemetry is still framework telemetry | NOT_DETERMINABLE |
| N-6 | That an agent reported everything it did | Silence leaves an intact chain | NOT_DETERMINABLE from AIRI |
| N-7 | That a chain was not truncated at the head | A prefix of a valid chain is valid | NOT_DETERMINABLE from AIRI |
| N-8 | That `runtime_binding` is true | Self-reported; a compromised process can report its real pid | by design |
| N-9 | That an MCP or API gateway's report is authoritative | Its key lifecycle and transport are undefined | NOT_DETERMINABLE |
| N-10 | Any post-quantum property | No PQC exists on this branch | NOT_DETERMINABLE |
| N-11 | That AIRI improves detection today | AIRI contributes nothing to a verdict at this stage | by design — see `AIRI_MIGRATION.md` §4 |

## 3. The JAX / PyTorch / accelerator chain

```
Python  →  PyTorch / JAX / TensorFlow  →  XLA / native runtime  →  CUDA / device
   ▲                    ▲                          ▲                     ▲
   │                    │                          │                     │
 AIRI is             reported to             reported to            NOT OBSERVABLE
 authored            AIRI by the            the framework           from inside the
 here                framework              by the runtime          process
```

| Layer | Observable from AIRI? | What is recorded |
|---|---|---|
| Which model the agent requested | yes | `model_id`, signed |
| Which model the provider served | **no** | nothing |
| Framework and version | yes, self-reported | `runtime`, `runtime_version` |
| Weights loaded | **no**, unless measured externally | `model_digest`, normally `None` |
| XLA / kernel launch | **no** | nothing |
| GPU execution | **no** | `accelerator`, a self-reported string |

Where the distinction matters, the answer is `CANNOT_PROVE`, and
`corroborate` returns `NotEvaluated(NotExternallyObservable)` for every model
event rather than borrowing the tool layer's socket as evidence.

## 4. Replay semantics for non-deterministic inference

Replay means **policy and evidence equivalence**, never bitwise reproduction
of model output. Two runs of the same prompt legitimately differ. What must
reproduce is the commitment structure: the same prompt bytes commit to the
same digest, and the signed binding between agent, execution, expectation and
model survives re-verification.

## 5. Inherited forensic blockers

AIRI does not close any of these. They are properties of the substrate it
sits on, and all remain **OPEN**.

| ID | Blocker | Status |
|---|---|---|
| B-1 | Verifier has no clock | **CLOSED** in `aip-protocol` (R16) |
| **B-1a** | `aip-service` supplies no verification time, so its `/verify` is unbounded | **OPEN (P1)** |
| B-2 | Delegation issuer not bound to previous grantee | **CLOSED**, fully adopted |
| B-3 | Containment unreachable from engine output | OPEN |
| B-4 | Bundle verified against a self-supplied key | OPEN |
| B-5 | Private keys written with default permissions | OPEN (the Python SDK refuses to *read* such a file, which is not the same as fixing the writer) |
| B-6 | Service mints a new identity on an unreadable key | OPEN in `aip-service`; the SDK's own loader fails closed |
| B-7 | Private seeds accepted in HTTP bodies | OPEN |
| B-8 | Packet replay undetected | OPEN |
| B-9 | `Reconciliation` constructible outside the engine | OPEN |
| B-10 | `aip-service` in no workspace | OPEN |

**Production promotion remains forbidden** until these are closed and tested.
Both P0s were closed by prod after this document was first written and were
independently verified; see
`audit/2026-09-06-airi-extension/P0_VERIFICATION_ADDENDUM.md`.
